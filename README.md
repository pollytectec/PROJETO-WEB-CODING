# API de Livros

## Objetivo
Criar uma API simples com Python e Flask para disponibilizar três livros em formato JSON.

## Instalação
1. Crie e ative um ambiente virtual.
2. Instale as dependências:

```bash
pip install -r requirements.txt
```

## Execução

```bash
python app.py
```

## Rota
Acesse no navegador:

http://127.0.0.1:5000/livros

A rota utiliza o método GET e retorna os três livros com id, titulo, autor e ano.
